How it works

01

PIPELINE

Input → cloud mask → overlapped tiling → RRDBNet 4× → feathered stitching → georeferenced GeoTIFF at 2.5 m, CRS preserved.

02

MODEL

RRDBNet generator, 23 residual-in-residual dense blocks, fine-tuned on SEN2NAIP — 61,282 Sentinel-2 / NAIP pairs.

03

UNCERTAINTY

Test-time augmentation across eight flips and rotations. Disagreement between passes marks where the model is least confident.

04

STATUS

Pipeline working end to end. Fine-tuning on Indian imagery from ISRO Bhoonidhi and quantitative validation in progress.
